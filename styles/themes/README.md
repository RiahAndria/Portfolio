# Visual themes

The portfolio now exposes two independent visual dimensions:

- `data-layout="terminal"` or `data-layout="classic"` controls the component structure and interaction language.
- `data-theme="light"` or `data-theme="dark"` controls the color and contrast system.

`theme-tokens.css` is the shared semantic layer. `classic.css` contains the first isolated classic palette and typography foundation. The existing terminal interface remains the default until the classic layout is deliberately activated by a future control.
